# 같은 거리, 다른 걸음 · v0.1

실제 카카오맵에 새장골경로당과 연서시장 두 지점을 표시하는 React + Vite 프로토타입입니다. **보행 경로 또는 체감거리 결과는 아직 포함하지 않습니다.**

## 로컬 실행

1. Node.js 설치
2. `npm install`
3. `npm run dev`
4. 터미널에 표시된 주소를 카카오 개발자 콘솔의 **JavaScript SDK 도메인**에 등록
5. 화면의 '지도 설정'에서 JavaScript 키 입력

## 브라우저 실행

StackBlitz에서 Vite/React 프로젝트를 열고 압축을 해제한 폴더의 파일들을 업로드합니다. 미리보기의 **실제 원본(origin)** 주소를 카카오 JavaScript SDK 도메인에 등록해야 합니다. 임베드 미리보기에서 인증 오류가 나면 `Open in New Tab`으로 실제 사이트 원본을 확인하세요. 호스팅 주소가 바뀌면 SDK 도메인 등록도 수정해야 합니다.

## 정식 배포

Cloudflare Pages 또는 GitHub Pages 등 HTTPS 호스팅을 이용하고 해당 도메인을 등록합니다. JavaScript 키는 공개형 키이지만 도메인 등록으로 제한해야 합니다. `VITE_KAKAO_MAP_KEY`는 최종 번들에 포함될 수 있으므로 관리자 키나 REST API 키를 절대 입력하지 마세요.
